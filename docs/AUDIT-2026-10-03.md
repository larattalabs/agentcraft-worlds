# Hardcore readiness audit (2026-10-03)

Four read-only audits of `main` at 0229f96: Hardcore safety, a multi-building village, check-in /
interaction UX, real-backend readiness. Verdict: **not ready yet**. The dev/HQ machinery is fenced off
from normal worlds and the core loop works against the sim, but nothing has run on real Claude, and
there are blockers in every area. Evidence (file:line) is in the session transcript; the summaries below
are the work list.

## Blockers

Survival safety / irreversible loss
- B1 Non-pausing screens (hub, decisions, diff, console, task, library, design, wizard, agent card), and a
  plain right-click on an agent NPC (eating, shield, bow, placing) opens its card. Pause in Hardcore;
  card only on empty-hand sneak+right-click; agents not pickable otherwise.
- B2 Remove restores the snapshot over the whole box with drops suppressed: chests/beds/items added
  later are destroyed; `clearDrops` also deletes the player's dropped items near the box. Refuse and
  list foreign block entities/items; only clear drops caused by the placement.
- B3 No server-side occupancy check at placement: player (client check is feet/head only), pets and
  mobs end up sealed inside / in walls. Refuse when a living entity intersects the box (mobs: offer to
  push out).
- B4 Every vanilla lectern opens the AgentCraft library (can't read or place books). Only intercept
  lecterns inside a building.
- B5 `D` / `/diff` open the oldest merge, not the selected one (`DiffLink.setOpener` never called), and
  Ctrl+Enter merges without confirm: the wrong merge can be approved.

Real backend
- B6 a non-empty `connectors` list disables strictMcpConfig; the connector gate allows tools whose
  `mcp_server` provenance is missing, so every claude.ai connector on the account (mail send, chat,
  file delete, accounting) may load into agents. Now: `connectors: []`; code: fail closed.
- B7 Commands that run a work repo's app or tooling (`dotnet run`, `func`, `dotnet ef`, `sqlcmd`,
  `az` verbs outside the deny list) could reach live services from an agent worktree and rely on the
  auto classifier alone. Deny commands that could reach live services from a work repo.
- B8 An approved edit to a `protect`ed file stays uncommitted: CI passes with it, the PR lands without
  it, silently. Keep source files out of protect (local config only); refuse landing with uncommitted
  protected edits and list them in the merge decision.
- B9 Launch story: a Foreman started from Prism/GUI gets launchd's PATH (no mise node, dotnet, az, gh,
  cargo). Start it through a login shell (`zsh -lic`), from a stable clone on its own port.
- B10 Lead assignments leak across worlds: leads held by any other world (dev HQ, a test or dead save)
  make every building in the new world overflow to Marlow, forever. Expire unsynced worlds; hub button
  to release them.
- B11 Phase 0 not run (real Claude, throwaway-instance soak with the 29 mods); Iris is installed in the
  instance although dropped; no 26.3 world backup exists yet.

## Should-fix

Village
- Goals stay with Marlow after a building is re-placed or a lead moves; adopt open goals on assign.
- Fluids invisible to placement (ray and ground search pass water/lava; ghost doesn't flag them).
- Worker decisions go to the home podium; console terminal ignores its building's repo; monitors,
  merge station and goal lamp are global in every building; podium bubble filtered but click global.
- Change a building's repos without re-placing; a 5-repo project fits no bundled campus (max 4 wings):
  say so and offer Design new / a split.
- Wooden front doors (zombies break them on Hard); the studio's dark corner.
Check-in
- Free text on Post/Skip and Fold in/Leave it decisions is discarded as Skip.
- The away digest is only on the Goals tab and `H` opens Buildings; blocked tasks, usage pauses and
  agent replies are transient toasts only (add a persistent HUD line).
- Agent card only reachable by right-clicking the NPC; Review hidden for non-oldest decisions; dead
  ends (diff/console don't return to their parent); Enter means different things per screen; plain
  console text silently creates a goal; two message channels (goal thread vs @agent).
- `B` clashes with Xaero's new-waypoint key; 4K + auto GUI scale (~426x240 GUI px) is below what was
  tested; no onboarding/help, no hub badges, toasts point at console commands.
Backend robustness and cost
- One network failure at start marks auth failed until restart; auth regexes too broad (`401`, `auth`).
- Non-limit turn failures (network, sleep, 529, max_turns) go to blocked and wait for a manual retry;
  failed plans fail the goal.
- Lead sessions per goal grow for weeks (no rotation); usage-limit wake after sleep relies on a timer.
- Cost: 4 parallel Opus leads with no `maxConcurrentTurns`, no per-turn budget, nothing reserved for
  the user's own Claude use. Start with `leads: ["marlow"]`, `maxConcurrentTurns: 2`,
  `maxBudgetUsdPerTurn`.
- `ANTHROPIC_API_KEY` in the env bypasses the claude.ai login; AgentCraft trailers/footers in work
  repos' commits and PR text; some repos without `baseBranch`; daily Foreman shares ports/checkout
  with dev runs.
Crash safety
- Unguarded client tick handlers (an exception crashes client + integrated server); remove deletes the
  snapshot before the world saves.

## Overhaul candidates (after real use)
- Terrain fit: foundations/skirt, footprint-median height, cleared margin (slopes leave floating floors
  and buried walls).
- Move building (keeps id, lead, goals, repos).
- One Inbox/Team surface for decisions, replies, blocked tasks, agent cards and logs, with in-world
  blocks deep-linking into it and one shared answer component.
- Phone/Discord notifications via a user-supplied webhook script.
- Walking routes between buildings (teleport today).

## Decisions for the user
- Iris: remove from the instance, or keep shaders off and include it in the soak.
- Hub Teleport in a cheats-off run: keep or disable.
- World lock-in: buildings are AgentCraft blocks; the world can never be opened without the mod.
- Starting lead count and caps for usage.
- AgentCraft trailers in work repos' commits/PRs.
